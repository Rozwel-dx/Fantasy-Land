涉及的切分策略与特性开关
类别	名称	影响
切分	TP（张量并行）	Q 头数 H_q_local=64/TP；MoE 中间维 I/TP
切分	SP（序列并行，enable_sp/enable_flashcomm1）	HC 算子第一维 T_hc = T/TP（不开启时为 T 且不切分）
切分	EP（专家并行）	E_loc = n_routed_experts/EP
切分	显存分配（受 DP/TP 间接影响）	num_blocks、部分 block_size
特性	--block-size / Ascend patch	Indexer KEY cache 的 block_size（1024 vs 128）
cmp_ratio、coff、head_dim、q_lora_rank、kv_lora_rank 等属于模型/层配置，非切分策略，下面不列。

一句话总结
受 TP：Q 投影的 wq_b 系、O 投影系、SparseAttnSharedkv 的 q、MoE 共享专家的 w1/w2
受 SP/flashcomm1：全部 HC 算子、MoE 的 gate/dispatch 系、通信算子（第一维 1024 vs 8192）
受 EP：DispatchFFNCombine 的 E_loc
受显存分配：所有 KV cache/state_cache 的 num_blocks
受特性（block-size/patch）：Indexer KEY cache 的 block_size
不切分：wq_a、kv 投影、Indexer q 投影、weights_proj
